# New Booking Accept Timer — Design spec v1

Design spec for the Wiom Partner App new-booking flow: a visible accept timer on
the bubble, booking screens and home card; acceptance moved to the date screen;
an automatic hand-off to the team list; and a success screen that becomes the drilldown.

`index.html` is a self-contained page (screens in `img/`), published with GitHub Pages.

**Internal-facing.** Contains Wiom pilot metrics. The page is excluded from search
engines (noindex + robots.txt), but anyone with the link can read it. Share deliberately.
